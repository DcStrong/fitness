# Роли и карта фич

Источник: фреймы «Fitness Yoda», «Обзорная».

## Роли

### Тренер (primary)

Из блока требований на доске:

**Основное**

- управление тренируемыми;
- управление доходами;
- график тренировок;
- уведомления о ближайших тренировках;
- экран статистики (занятость, доход, расписание);
- форма записи нового подопечного;
- развёрнутый календарь тренировок;
- форма записи групповых тренировок;
- взаимодействие с пользователями системы.
- управление публичным профилем, портфолио и приватностью;
- просмотр подтверждённых отзывов и производного рейтинга.

**Дополнительно (позже)**

- возможность составлять программу тренировок;
- регистрация подопечных;
- внесение статистики тренировок.

### Студент / клиент

- запись к тренеру (при установленном приложении);
- календарь / план / дневник;
- уведомления;
- профиль, приватность;
- просмотр планов по тегам;
- лента публичных профилей тренеров;
- проверенные отзывы после проведённого занятия;
- приватность авторства отзыва.

Один пользователь теоретически может иметь обе роли — это нужно решить отдельно (см. открытые вопросы в roadmap).

## Карта модулей

```text
Вход
├── авторизация
├── регистрация
├── приглашение (QR)
└── рефералы

Роли
├── тренер
└── студент

Профиль
├── портфолио
├── рейтинг
├── отзывы
├── ярлыки (тэги)
└── настройки приватности

Тренировки
├── календарь
├── план тренировок
├── дневник тренировок
└── уведомления

Деньги
├── бухгалтерия
└── кошелек

Социальное
└── лента тренеров
```

## Приоритет модулей для разработки

| Приоритет | Модуль | Почему |
|-----------|--------|--------|
| P0 | авторизация / регистрация / роли | Без этого нет продукта |
| P0 | приглашение (QR) | Главный способ связать тренера и студента |
| P0 | календарь / график / занятие | Ядро процессов на доске |
| P0 | запись (оба сценария) | Основной use case |
| P0 | подтверждение занятия | Закрывает цикл «было / не было» |
| P1 | план тренировок | Связка CoachSchedule ↔ StudentSchedule ↔ Plan |
| P1 | уведомления + история | Следствие записи |
| P1 | теги | Группы людей и общие планы |
| P2 | бухгалтерия / фактура / кошелёк | Есть на процессных диаграммах как опциональное |
| P2 | статистика тренера | Зависит от истории занятий |
| P3 | лента / отзывы / рейтинг / портфолио / приватность | Рост и доверие; vertical `social-privacy` |
| P3+ | рефералы | Отдельный будущий change |

## Экраны / сценарии тренера (черновик)

1. Онбординг / логин.
2. Главная: ближайшие занятия + быстрые действия.
3. Календарь (день / неделя).
4. Подопечные (список, карточка, запись).
5. Создать / подтвердить занятие.
6. Планы и теги.
7. Статистика (позже: доход / занятость).
8. QR-приглашение (показать / поделиться).
9. Публичный профиль: черновик, публикация, портфолио, отзывы.

## Экраны / сценарии студента (черновик)

1. Скан QR / deep link → регистрация / логин.
2. Главная: ближайшее занятие + план.
3. Запись к тренеру по слотам.
4. Дневник / история.
5. План тренировок (в т.ч. по тегам).
6. Профиль / приватность.
7. Лента и публичная карточка тренера.
8. Отзыв после `completed` Session.
