# Design mockups

Каноническое место для UI-макетов Fitness Yoda (PNG/WebP).

## Именование

`fitness-yoda-<feature>-<variant>.png`

Примеры:

- `fitness-yoda-trainer-calendar-concept.png`
- `fitness-yoda-calendar-day-week-month-v2.png`
- `fitness-yoda-availability-fixed-grid-v1.png`

## Правило для агента / чата

Новые макеты (GenerateImage и т.п.) **сразу сохранять сюда**: `docs/assets/`, не в
`~/.cursor/projects/.../assets/` и не в корень репо.

В OpenSpec / docs ссылаться относительно репозитория:

`docs/assets/<filename>.png`

Скриншоты аннотаций из чата можно оставлять во временной Cursor-папке; в git
переносим только именованные product-макеты.
