## Why

Экраны ученика, занятия и тегов уже умеют нужные действия, но иерархия как у админ-ленты: равноправные карточки-кнопки, полный ряд тегов и несколько CTA одного веса. Тренеру мешает шум, а контент (человек, состав занятия, группы тегов) не читается. Макеты в `app/design/generated/` фиксируют смысл — не pixel-perfect.

## What Changes

- Хаб ученика (`/students/:id`): шапка человека (имя, абонемент, ближайшее занятие), блок «на этой неделе» + программа, список тренировок с «Назначить», прогресс; компактная сетка 2×2 (записать / назначить / абонемент / программа) вместо ленты равноправных карточек-кнопок.
- Страница занятия: состав и веса занимают экран; одна primary «Проведена»; состав/смена — текстовые ссылки; неявка / отмена / история — тихо или в ⋯. Навигация (программа, история) не masquerade под CTA. Кнопки — `FyButton` / одна иерархия.
- Библиотека тренировок: 4–5 популярных или недавних тегов + «Ещё»; остальные только в шите поиска (`mock-tags-search-sheet`).
- Экран тегов: карточки-группы с составом, без корзины в каждой строке; удаление — внутри хаба или overflow, не CRUD-список.

## Non-goals

- Не менять Nest API без необходимости (счётчики состава — с существующих hub/list данных на клиенте).
- Не трогать web.
- Не копировать лишние кнопки, табы и фильтры, которые нейросеть дорисовала на макетах (5-tab chrome, «Сообщения», «Группы» в таббаре, Difficulty/Equipment на фоне шита, «Смотреть все», pixel-perfect фото вместо инициалов).
- Не pixel-perfect; не новая дизайн-система; не смена контрактов complete/assign/tags.

## Capabilities

### New Capabilities

- (нет) Поведение укладывается в существующие mobile-спеки.

### Modified Capabilities

- `mobile-student-hub`: информационная архитектура хаба (шапка, неделя, сетка действий, тренировки, прогресс).
- `mobile-session-workout`: иерархия действий на `/sessions/:id` (один primary, текстовые ссылки, overflow).
- `mobile-session-lifecycle`: те же lifecycle-действия, но без равноправных кнопок на странице занятия.
- `mobile-workout-templates`: компактный ряд тегов в библиотеке + шит «все теги».
- `mobile-plans-tags`: список тегов как группы, без delete в строке.
- `mobile-workout-program`: вход «Программа» с хаба ученика (ссылка в шапке недели / сетке), без смены редактора программы.

## Impact

- Flutter: `student_hub`, `session_workout`, `plans` library + `tags` list, виджеты `FyButton` / text-link / overflow. Маршруты те же (`/students/:id`, `/sessions/:id`, `/plans`, `/tags`).
- Backend / web: без изменений, если клиент соберёт «эту неделю» и состав тега из уже доступных payload.
- Тесты: widget/golden не обязательны; обновить ключи и e2e, если селекторы завязаны на `FilledButton`/`OutlinedButton` или иконку корзины в списке тегов.
